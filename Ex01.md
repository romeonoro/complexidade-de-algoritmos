```c
int obter(int vetor[], int i) {
    return vetor[i];
}
```

- **a)** Quantas operações primitivas são realizadas?  
  **2**

- **b)** A complexidade depende de n?  
  **Não.**

## Exercício 2 — contagem em um vetor

```c
int contarPares(int vetor[], int n) {
    int quantidade = 0;

    for (int i = 0; i < n; i++) {
        if (vetor[i] % 2 == 0) {
            quantidade++;
        }
    }

    return quantidade;
}
```

- **a)** Quantas vezes a condição é avaliada?  
  **n**

- **b)** A quantidade de incrementos pode mudar?  
  **Sim.**

- **c)** Qual é a complexidade no melhor e no pior caso?  
  **Θ(n) e Θ(n).**

## Exercício 3 — dois laços sequenciais

```c
for (int i = 0; i < n; i++) {
    printf("%d\n", vetor[i]);
}

for (int j = 0; j < n; j++) {
    soma += vetor[j];
}
```

- **T(n):** **2n = Θ(n)**.

- **Por que não é Θ(n²)?**  
  Porque os laços são sequenciais, não aninhados.

## Exercício 4 — laços aninhados

```c
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        comparacoes++;
    }
}
```

- **Quantas vezes `comparacoes++` é executada?**  
  **n²**

- **Qual é a classe de crescimento?**  
  **Θ(n²)**

## Exercício 5 — análise de casos

```c
int contem(int vetor[], int n, int x) {
    for (int i = 0; i < n; i++) {
        if (vetor[i] == x) {
            return 1;
        }
    }

    return 0;
}
```

- **Melhor caso:** `x` está na primeira posição.

- **Pior caso:** `x` está na última posição ou não está no vetor.

- **Caso médio:** `x` tem a mesma chance de estar em qualquer posição.

- **a)** Quantas vezes a condição é avaliada?  
  **Melhor: 1. Pior: n.**

- **b)** A quantidade de incrementos pode mudar?  
  **Não há incrementos no código.**

- **c)** Qual é a complexidade no melhor e no pior caso?  
  **Melhor: Θ(1). Pior: Θ(n).**
